# Pantalla 05 — Detalle de fiestuca

**Objetivo:** ver el programa y decidir si acudir.

## Contenido

Nombre, localidad, recinto/dirección cuando conste, fechas, cartel original ampliable, descripción breve y cronograma agrupado por día. Cada actividad muestra hora confirmada o «Hora por confirmar», nombre y categoría; artistas, comida e infantil se derivan de actividades verificadas, sin inventar etiquetas. Mostrar fuente enlazada cuando exista, autor/organizador si procede, nivel **Oficial / Verificada / Comunidad**, fecha de última comprobación y aviso de cambios/cancelación.

## Acciones

Guardar/quitar, compartir enlace profundo con alternativa web, abrir navegación externa a coordenadas/dirección, reportar error o cambio y abrir cartel accesible. Si una hora cruza medianoche, mantener su fecha local correcta. El detalle de una fiesta cancelada muestra la cancelación antes del programa.

## Estados y aceptación

Cartel ausente: cabecera gráfica neutra; fuente incompleta: mostrar «Fuente pendiente de verificar» y facilitar reporte. Error de carga: reintento; si hay caché, etiqueta de posible desactualización. Confirmar que compartir abre el evento correcto, que el programa se ordena por fecha y hora y que no se presenta una propuesta pendiente como publicada.
